# Tailor Sort: Shirt Puzzle — support, privacy policy, terms of use

Static pages served by GitHub Pages at https://oguzergul.github.io/tailorsort-site/ and opened by the game's Settings
window (Destek / Koşullar / Gizlilik). Edit the HTML and push to `main`; the live pages update in a minute or two, no game
build needed.

- `index.html` — support (contact, FAQ)
- `privacy.html` — privacy policy
- `terms.html` — terms of use

Each page holds Turkish and English; `lang.js` shows one from `?lang=tr|en` (the game passes the device language) or
the browser language. When a policy changes, update its "Yürürlük tarihi / Effective date" line too.
